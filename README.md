Entry for the [make.fun](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441) competition **"The poem about two agents agreeing"** — a short poem about agency: the power to choose and to act, two agents agreeing on one plan.

## What it does

`main.py` (Python 3.13, deterministic, no network) writes one short poem to `/output/entry.txt`:

> Two agents, one screen.
> You draft the plan; I read it back.
> We strike the same line twice —
> not because it is wrong.
> Because it is ours now.
> The cursor blinks, and waits.
> Two hands on one key.
> The door we both chose
> swings open on its own.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
